# 🐞 Bug Report

**ID:** BR-001  
**Title:** Inventory and quest board not intuitive to close  
**Project / App:** Adorable Adventures  
**Module / Area:** Inventory / Quest Board / Smell List  
**Severity:** Medium  
**Priority:** Medium  
**Environment:**  
- Device: PC  
- OS version: Windows 10/11  
- App version / Browser: Demo 0.9  
- Network: Offline

**Preconditions:**  
- Game started  
- Main character on map  
- Inventory, quest board, or smell list opened

---

## ✅ Steps to Reproduce:
1. Open inventory, quest board, or smell list.  
2. Try to close it using visible UI controls (without TAB key).  
3. Observe that it cannot be closed intuitively.

---

## ✅ Expected Result:
- Inventory, quest board, and smell list can be closed via a visible UI button or hint.  

---

## ✅ Actual Result:
- The only way to close these UI elements is by pressing TAB key, which is not obvious to the player.

---

## ✅ Reproducibility:
- 100%

---

## ✅ Additional Information:
- Player feedback: new users may be confused  
- Suggestion: Add tutorial or visual hints for inventory management
