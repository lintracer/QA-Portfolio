# 🎮 Game Testing — Adorable Adventures (Demo)

**Project:** Adorable Adventures (Demo)  
**Platform:** PC / Windows 11 
**Period:** Feb 2026 - Mar 2026
**Role:** QA Tester — exploratory and functional testing

**Adorable Adventures beta testing** – 6 confirmed bugs + UX observations

---

## ✅ What I did
- Installed and tested the demo build on PC.  
- Performed exploratory testing across core gameplay flows: character movement, inventory management, quest mechanics, environmental interaction, and UI navigation.  
- Verified stability, game mechanics, and UI/UX consistency.  
- Documented bugs and provided suggestions to improve gameplay and user experience.  
- Submitted bug reports with reproduction steps, screenshots, and videos where applicable.

---

## ✅ Example contributions / Bug Reports
- **Inventory / Quest Board navigation:** Closing inventory, quest board, and smell list was not intuitive; discovered method is TAB key. Suggested adding tutorial or instructions for inventory management.  
- **Character movement / sprint:** During sprint, the main character (wild boar piglet) accelerates too fast, making control difficult.  
- **Collision physics / jumps:** Piglet sometimes collides with objects and is launched to unrealistic heights; expected behavior would be more realistic fall mechanics.  
- **Quest mechanics:** Verified quest flow for helping injured brother using herbs and progressing to the "lair" works correctly.  
- **Interactive environment:** Tested various objects and locations; most functionality intuitive and visually appealing, but suggested minor improvements for player guidance.  
- **UI/UX suggestions:** Recommended adding a full tutorial for inventory and special mechanics to improve onboarding for new players.
